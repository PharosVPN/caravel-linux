# caravel-linux

PharosVPN client for Linux — a Wails (Go + web) desktop app matching the macOS
client, packaged as an AppImage for broad distribution.

See [docs/cloud-sync.md](https://github.com/PharosVPN/docs/blob/main/cloud-sync.md)
for the cloud-sync UX contract, and `caravel-mac` for the reference UI.

> Scaffolding in progress.
